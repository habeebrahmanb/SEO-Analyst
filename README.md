## ✨ Features

- **Hero Section**: Eye-catching presentation with dynamic stats, key performance metrics, and call-to-action buttons.
- **Interactive SEO Audit Calculator**: Estimate audit costs and timeline dynamically based on website size, goals, and target features.
- **Services Showcase**: Detailed overview of core SEO services (Technical SEO, On-Page Optimization, Content Strategy, Link Building, etc.).
- **Portfolio & Case Studies**: Interactive gallery showcasing client success stories, keyword ranking improvements, and traffic growth.
- **Blog Section**: Informative industry insights, guides, and SEO best practices.
- **Contact & Booking System**: Full-featured contact form with service selection and direct booking options.
- **WhatsApp Integration**: Floating WhatsApp widget for fast client communication.
- **Responsive & Dynamic Design**: Polished dark theme layout with smooth glassmorphism effects and animations.

## 🚀 Getting Started

### Prerequisites

Ensure you have **Node.js 18.x** or higher installed on your system.

### Installation

1. Clone the repository or navigate to the project directory:
   ```bash
   cd "SEO Analyst"
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally

Start the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

---

## 📦 Build & Deployment

To build the application for production:
```bash
npm run build
```

To start the production server locally:
```bash
npm run start
```
